# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `@mcpbundles/mcp-connect-auth`, please report it responsibly.

Email **support@mcpbundles.com** with:

- A description of the vulnerability
- Steps to reproduce the issue
- Any proof-of-concept code or logs (if applicable)
- Your contact information for follow-up

We aim to acknowledge reports within two business days and will work with you on a coordinated disclosure timeline.

Please do not open public GitHub issues for security vulnerabilities.
