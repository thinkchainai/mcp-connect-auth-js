# @mcpbundles/mcp-connect-auth

Node.js client library for [MCP Connect Auth](https://www.mcpbundles.com/docs/integrations/mcp-connect-auth) on MCPBundles.

- HTTP middleware for MCP routes (protected-resource + JWT verify)
- `completeFederation()` — finish OAuth federation after your sign-in flow
- Optional origin handshake telemetry on MCP `initialize`

**Status:** Scaffold only — implementation tracked in the MCPBundles monorepo (`product/mcp-connect-auth/coding-plan.md`).

```bash
npm install @mcpbundles/mcp-connect-auth  # not published yet
```
